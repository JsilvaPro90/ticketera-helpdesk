# Changelog - Ticketera Helpdesk

Todos los cambios importantes del proyecto serán documentados en este archivo.

---

## [v1.0.0] - 2026

### 🚀 Versión inicial

Primera versión funcional del sistema web de gestión de tickets para soporte TI.

### ✨ Funcionalidades implementadas

- Registro y gestión de usuarios.
- Administración de entidades y contactos.
- Creación y seguimiento de tickets.
- Clasificación de incidencias.
- Gestión de estados del ticket.
- Dashboard operativo.
- Registro de información mediante base de datos SQL Server.

### 🛠 Tecnologías utilizadas

- C#
- ASP.NET MVC
- Entity Framework
- SQL Server
- HTML / CSS / JavaScript
- Git y GitHub
